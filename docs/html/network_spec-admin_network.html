Parameter

Details

admin_network

dict / required

Admin network configuration. Essential for PXE boot and host communication.

oim_nic_name

string / required

The name of the interface on the OIM server associated with the admin network.

Example value: eno1

subnet

string / required

The canonical IPv4 network address for the admin network. It must not overlap another primary or additional admin subnet, or the optional InfiniBand subnet.

Example value: 172.16.107.0

netmask_bits

string / required

The number of bits in the subnet mask.

Example value: 24

primary_oim_admin_ip

string / required

The OIM admin IPv4 address. It must belong to the primary admin subnet and remain outside that subnet's dynamic range.

Example value: 172.16.107.254

primary_oim_bmc_ip

string / required

The OIM BMC/iDRAC IP address. Specify an IPv4 address to include the OIM in the generated BMC group data consumed by iDRAC telemetry. Set the value to an empty string to exclude the OIM. A non-empty value must differ from every OIM admin address and remain outside every configured DHCP range.

Example value: ""

router

string / required

In connected deployments, the router field should typically be set to the external rack gateway, such as a SONiC switch, which provides connectivity beyond the rack network. In air-gapped deployments, the router field can be set to the OIM’s IP address if the OIM is acting as the rack gateway. If another dedicated router or gateway is available, its IP address should be specified instead. The configured value must belong to this subnet and is advertised to nodes via DHCP as their default gateway.

Example value: 172.16.107.254

dynamic_range

string / required

An ordered start-end IPv4 range contained by this subnet. It must not contain the OIM admin or BMC address and must not overlap another configured DHCP range. The current precheck does not cross-check the pool against PXE mapping addresses; reserve static node addresses outside the pool.

Example value: 172.16.107.201-172.16.107.250

dns

list / elements=string

The list of external DNS server IP addresses for the admin network.

Example value: []

ntp_servers

list / elements=dict

The list of NTP servers for the admin network. Each NTP server entry should include address (IP address or hostname) and type (server or pool).

Example value: []

address

string / required

IP address or hostname of the NTP server.

type

string / required

NTP source type. Accepted values: server, pool.
