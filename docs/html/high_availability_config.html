Parameter

Details

service_k8s_cluster_ha

list / elements=dict / required

High Availability (HA) configuration for Kubernetes (K8s) service clusters. Configure exactly one entry. Orchestrator validates it against the Kubernetes cluster selected for deployment and generates kube-vip configuration from its virtual IP address.

cluster_name

string / required

Identifies the intended service cluster. This value must match the single service_k8s_cluster entry selected with deployment: true in omnia_config.yml.

enable_k8s_ha

boolean / required

Possible values: true or false

Set this value to true for the supported HA configuration. The current provisioning role reads the value but does not use it to disable kube-vip generation.

virtual_ip_address

string / required

This is a mandatory and user-configurable parameter.

Captures the virtual IP address for the K8s service node HA setup. Ensure that the virtual_ip_address does not belong to the dynamic_range mentioned in the network_spec.yml.

Sample value: 172.16.107.1

Input validation requires this VIP to be a usable address in the shared control-plane admin subnet, requires the complete MetalLB pool to belong to that subnet, and rejects conflicts with OIM, mapped node, DHCP, and MetalLB addresses.
