Parameter

Details

mounts

list / elements=dict

Cloud-init compatible mount configurations. Source must be known at boot time. Each entry must define exactly one targeting field: functional_group_prefix or groups.

name

string / required

Unique identifier for this mount entry

source

string / required

Device name or network path (e.g., /dev/sdc, UUID=xxx, 192.168.1.100:/export/share, powervault:<name>)

mount_point

string / required

Mount point path

fs_type

string

Filesystem type. Overrides mount_params profile when specified.

Default: auto.

mnt_opts

string

Mount options. Overrides mount_params profile when specified.

dump_freq

string

Dump frequency (usually 0). Overrides mount_params profile when specified.

Default: 0.

fsck_pass

string

Fsck pass number (usually 0 or 2). Overrides mount_params profile when specified.

Default: 0.

mount_params

string

Named profile key from the mount_params section. Use an existing profile. The current runtime does not reject an unknown name and instead falls back to auto, defaults, 0, and 0 for the filesystem, mount options, dump frequency, and fsck pass.

mount_on_oim

boolean

Whether to mount this filesystem on the OIM node. Default: false. Ensure the storage system is accessible to OIM

Default: False.

node_key

string

Per-node subdirectory isolation variable. Optional and disabled when omitted.
Allowed values:
- local_hostname - hostname of the node
- local_ipv4 - IPv4 address of the node
- instance_id - instance ID of the node from cloud-init
When set, node_mount_point is required.
Generates bind mounts: <mount_point>/<node_key_value>/<target> -> <target>

node_mount_point

list / elements=string

List of bind mount target paths. Required when node_key is set.

functional_group_prefix

list / elements=string

List of OpenCHAMI functional group prefixes to apply this mount to. Exactly one of functional_group_prefix or groups is required.

groups

list / elements=string

List of GROUP_NAME values from pxe_mapping_file.csv. Exactly one of groups or functional_group_prefix is required.

permissions

dict

Directory ownership and mode commands generated for mount_point. The current command order applies them before mount -av, so they affect the underlying local directory rather than guaranteeing permissions on the mounted filesystem.

owner

string

User owner of the mount point (name or numeric UID)

Default: root.

group

string

Group owner of the mount point (name or numeric GID)

Default: root.

mode

string

Octal permission mode (e.g., 0755, 1777)

Default: 0644.
