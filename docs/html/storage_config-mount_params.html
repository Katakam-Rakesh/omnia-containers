Parameter

Details

mount_params

dict

Named mount parameter profiles. Each profile defines fs_type and mnt_opts, with optional dump_freq and fsck_pass. Custom fields are rejected.

<mount_params_key>

dict

Profile name referenced by a mount's mount_params value.

fs_type

string / required

Default filesystem type

mnt_opts

string / required

Default mount options

dump_freq

string

Default dump frequency

fsck_pass

string

Default fsck pass number
